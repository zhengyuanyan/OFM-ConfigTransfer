# Bekannte Limitationen（已知限制）

## 不支持通信对象（KO）

* 通信对象配置（组地址关联或 KO 标志）**无法**被传输。
* 写入配置时，通信对象会在没有通常确认的情况下被隐藏，同时丢失组地址关联。
* 通过导入重新可见的通信对象，可能仍含有更早的组地址关联。

## ETS 模块（例如多行注释）

* 迄今**不**支持 ETS 模块中的参数。

## 通道之间的差异

* 默认值依通道定义的参数无法被重置。

## 模块集成/模块版本造成的差异

* OpenKNX 模块内部改动过的参数默认值，可能导致导入时采用目标环境的默认值。

## Kanalkopie（通道复制）

允许复制通道配置，或可在模块内重组通道时提供帮助。


### 模块

<!-- TODO 冗余的说明文字需要更好的处理方式 -->
选择要在其通道之间复制配置的模块。
模块名称与 ETS 应用中配置页的标签名称一致。

部分模块可能已被应用创建者排除在配置传输的使用之外。
这些模块以及不含通道的模块不会出现在选择列表中。




### 源通道

选择用作复制模板的通道。

若所选模块不含任何通道，
或没有相应编号的通道，
通道复制将会失败。


### 目标通道

选择要用源通道配置覆盖的通道。

若所选模块没有相应编号的通道，
或目标通道被选为与源通道相同，
通道复制将会失败。


### 复制（按钮）

启动复制过程并覆盖目标通道。
此过程可能会耗时数分钟，且既不能中断也无法撤销！

> **注意**：复制前应确认，覆盖目标通道不会造成配置数据丢失！


### 复制结果

此处给出复制过程的反馈信息。
如有需要，可将输出复制到剪贴板；
一旦修改本页面上的其他任一参数，
输出就会被清空，以避免与所选设置产生矛盾。

该值不会在应用程序内被进一步处理。

### Transfer-String（传输字符串）

此处必须输入包含（序列化）配置、且采用受支持格式的字符串。
该字符串中还包含对所导入到的 OpenKNX 模块的引用。

一次初步的格式检查确保只接受*可能*包含完整 ConfigTransfer 字符串的输入。
但精确检查只会在点击*导入*按钮之后进行。

> 来自其他 ConfigTransfer 版本的导出均受支持，只要格式未发生变化。
  此处尚不能识别不一致的格式版本。



<!-- DOC -->
### Import-Ziel（导入目标）

确定应导入到模块内的哪个位置。


#### 自动采用导出中的设置

使导入发生在先前导出所在的同一通道。
前提是导出字符串中包含通道编号。

若使用与通道无关的 ConfigTransfer 字符串，
或指定的通道编号在本应用中未对该模块定义，
则使用此设置的导入将会失败。


#### 基础设置（与通道无关）

强制仅导入与通道无关的配置。

若使用与通道相关或与通道无关的 ConfigTransfer 字符串，
则使用此设置的导入将会失败。


#### n（1 至 99）

使通道配置被导入到所选的通道中，
无论其导出时来自哪个通道。

若使用与通道无关的 ConfigTransfer 字符串，
或指定的通道编号在本应用中未对该模块定义，
则使用此设置的导入将会失败。

### Modul（模块）

选择要导出其配置的模块。
模块名称与 ETS 应用中配置页的标签名称一致。

部分模块可能已被应用创建者排除在配置传输的使用之外。
这些模块不会出现在选择列表中。配置传输模块本身也不会出现在导出选项中。



<!-- DOC -->
### Inhalt/Kanal（内容/通道）

决定应导出模块配置的哪一部分：


#### 基础设置（与通道无关）

导出对所有通道通用、或与任何通道都无关联的配置。

即使不存在相应的配置项，此导出也始终可行。


#### n（1 至 99）

导出所编号通道的配置，
前提是该编号的通道存在。

若所选模块不含任何通道，或没有相应编号的通道，
导出将会失败。



<!-- DOC -->
### Exportierte Parameter（导出的参数）

确定对当前配置无影响的参数在导出中的收录范围。


#### 标准（仅激活且含自定义值的参数）

仅导出那些当前在 ETS 中显示、且满足下列条件之一的参数：
其值不等于默认值，
或
无论取值如何都必须始终导出。

此前做过、但因修改其他参数而被隐藏的设置会被排除在导出之外。

该设置可避免历史遗留继续留在配置中。
但由此产生的结果是：在再次导入时，行为会与源设备不同：
先前不可见的参数将恢复为默认值，而不再使用最后一次设定的值。


#### 包含未激活/不可见参数

同时导出那些曾经被设置为不同于当前默认值、但目前被隐藏/未激活的参数。
即便它们无法与当前已显示/激活的参数同时生效。

该设置可能*显著*增大导出体积，
但也提供了可能性，例如用于备选地表示针对不同输出类型的配置。


#### 包含默认值

导出所有可见参数，即使它们被设置为默认值。

该设置通常会使导出体积*显著*增大，
但在需要传输到默认值已变化的另一模块版本时可能会有帮助。


<!-- DOC -->
### Format（格式）

选择输出的形式。
它不影响导出的内容，
但决定了可采用何种后续处理方式。


#### 标准（用于导入与技术支持）

导出时不加换行，全部位于一行。
若要在他设备导入中使用该输出，这是必需的，
因为 ETS 不支持多行输入。


#### 多行（无法导入！）

**注意：** 除非模块开发者明确要求，否则不应出于技术支持目的使用此格式。

导出时会在每个配置值的前后各插入一个换行。

如果模块定义中使用了可读的参数名，
开发者在简单模块上或许能直接识别出特定设置。
